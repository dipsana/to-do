---

### ⭐ Overview

Initial stable release of the **To-Do List Web Application**, a responsive and interactive task organizer built with **HTML, CSS, and JavaScript**.
This version provides all the essential productivity features along with dark mode and background customization.

---

### ⚙️ Technical Notes

* Built using **Vanilla JavaScript** (no dependencies)
* Compatible with all major browsers
* Fully client-side — no backend or API calls required
* Lightweight build for fast load times

---

### 🧩 Known Limitations

* Tasks are stored only in LocalStorage (no cloud sync)
* No edit option for existing tasks yet
* Limited validation for invalid date input
